# شركة لبيب كمال للأدوات والآلات الزراعية — LKL

> **الجودة • الثقة • الخدمة المتميزة**  
> الزقازيق — الشرقية — مصر (البداية، طريق مصر الزراعي)

المنصة الرسمية المخصصة لعرض المنتجات والمعدات الزراعية، شبكات ومحركات الري، قطع الغيار، مع لوحة تحكم إدارية متكاملة ونظام طلب واستفسارات احترافي مبني باللغة العربية أولاً (Arabic-first & RTL-correct).

---

## 🛠 التقنيات المستخدمة (Tech Stack)
- **الإطار البرمجي (Framework):** [Next.js 15](https://nextjs.org/) (App Router & React 19)
- **لغة البرمجة:** [TypeScript 5](https://www.typescriptlang.org/) (Strict Mode)
- **التصميم وتنسيق الواجهات:** [Tailwind CSS](https://tailwindcss.com/) مع نظام رموز تصميم مخصص للعلامة التجارية (Green & Gold)
- **الأيقونات:** [Lucide React](https://lucide.dev/)
- **قاعدة البيانات:** PostgreSQL
- **المصادقة (Auth):** Google OAuth الرسمية وجلسات آمنة مع فصل دقيق للصلاحيات (RBAC)

---

## 🚀 بدء التشغيل المحلي (Getting Started)

1. **تثبيت الحزم البرمجية:**
   ```bash
   npm install
   ```

2. **إعداد متغيرات البيئة:**
   انسخ الملف `.env.example` إلى `.env.local` وقم بملء البيانات الخاصة بك.

3. **تشغيل خادم التطوير:**
   ```bash
   npm run dev
   ```
   افتح المتصفح على [http://localhost:3000](http://localhost:3000).

4. **فحص الأنواع وتدقيق الشيفرة:**
   ```bash
   npm run typecheck
   npm run lint
   npm run build
   ```
